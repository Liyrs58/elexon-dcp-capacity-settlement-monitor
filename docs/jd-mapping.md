# Job description mapping

| Role expectation | Project feature | Evidence |
| --- | --- | --- |
| Monitor data and risk | Executive metrics, trends and risk states | `web/index.html`, `/api/overview` |
| Identify issues promptly | Arrival versus processing and validation controls | `analysis.py`, `validation.py` |
| Investigate root causes | Workload segmentation and hypothesis tests | `hypotheses.py`, Hypothesis tests page |
| Analyse and visualise | Python calculations, SQLite queries and browser charts | `src/service_intel`, `sql/analysis.sql` |
| Validate key data | Blocking schema, type and reconciliation controls | `validation.py`, Validation panel |
| Support customer service | Customer impact view and deterministic service note | `/api/customer-impact`, `narrative.py` |
| Coordinate vendors | Service provider evidence checklist | Customer and Settlement impact page |
| Support service change | Scenario lab and improvement register | `/api/scenario`, `/api/improvements` |
| Maintain knowledge | Runbook, incident playbook and data dictionary | `docs/` |
| Communicate clearly | Plain English explanations and evidence limits | UI copy and `interview-demo.md` |

The project demonstrates the candidate’s method. It does not claim access to Elexon internal systems or decision authority.
